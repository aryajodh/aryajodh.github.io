# aryajodh.github.io

Welcome to the repository for my personal portfolio website, live at **[aryajodh.github.io](https://aryajodh.github.io)**. 
Designed using my favorite color and built to balance high-end UI/UX animations with a scannable structure, some may call it a live resume.

## Tech Stack & Features

* **Core Structure:** HTML5, CSS3, Modern JavaScript
* **Styling & Effects:** Custom CSS variables, smooth scroll physics, Bento Grid layout, and infinite-scrolling marquee tickers.
* **Hosting:** GitHub Pages
* **Key Sections:**
  * **Hero Intro:** Instant clarity on background (RPI Computer Science & Economics) and target roles.
  * **About Me (Bento Grid):** Academic focus, technical toolsets, and campus leadership.
  * **Featured Projects:** Showcase of full-stack apps (e.g., *TRRAM*) and hardware/maker ventures.
  * **Experience & Leadership Timeline:** Interactive professional timeline detailing engineering internships (Blue Origin, iD Tech, Code Ninjas) and governance roles.
  * **Professional Dossier:** Direct links for resume downloading, email contact, and LinkedIn networking.
